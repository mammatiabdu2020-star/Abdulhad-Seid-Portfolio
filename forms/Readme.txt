# Abdulhadi Seid - Portfolio Website

Welcome to the official portfolio website source files for Abdulhadi Seid, Frontend and Full-Stack Developer.

## Project Structure Overview
- index.html: Homepage with hero intro and overview.
- about.html: Personal background, details, and biography.
- resume.html: Education, experience, and professional summary.
- services.html: Overview of development and AI integration services.
- service-details.html: Detailed breakdown of technical capabilities.
- portfolio.html: Showcase of projects and web applications.
- portfolio-details.html: Detailed view of specific projects.
- contact.html: Contact form and professional location/email details.
- starter-page.html: Template file for adding new custom sections or pages.
- assets/ & forms/: Contains styles, JavaScript files, and form handlers.

## Setup & Deployment
1. Place all your vendor libraries, stylesheets, and images inside the `assets/` folder.
2. Open `index.html` locally in your web browser or via a code editor extension (like Live Server in VS Code).
